# 当前状态

状态：可提交展示的本地 MVP
更新时间：2026-08-30

## 已完成

- 最终命令面收敛为 `run-edge-monitor`、`serve-product`、`export-product-report` 和 `delete-product-data`。
- 目标 C6c 直播流按 60 秒连续内存处理；灰度运动量和音频 RMS 先选关键窗口，姿态/VAD/ASR 只处理选中内容。
- 原始音视频不在本机落盘；每段保存 path-free 审计、模型有效覆盖、失败码和云端时间引用。
- 跌倒、心理健康、诈骗分别输出规则型 `0–3/null`，绑定策略 revision 与 SHA-256；没有全局总分或自动外部告警。
- 每人 SQLite schema v4 支持旧库向前迁移，并保存日级个人特征、候选、assessment、人工复核、月度 WHO-5 和无媒体分段审计。
- 看板只显示“康盾”品牌，固定三域卡、28 天个人趋势、个人基线、月度问卷、近期事件、语音转写片段和 owner-only 复核备注。
- 异常候选支持前端按需播放事件前后云端画面与声音；临时 URL 只在点击时解析，关闭弹窗移除，不写入数据库或报告。
- HTTP 只允许 `127.0.0.1`；写请求要求精确同源、CSRF 和 JSON。无本地媒体或任意文件读取路由。
- owner/public 两套离线 HTML+JSON 使用同一评分结果；public 去除身份、设备、原始覆盖、转写、备注、路径、candidate 和精确时间。
- 合成演示强制使用 `demo-*` 假名，走真实存储、评分、问卷与复核链，不读取真实资产。
- 早期基准、Slurm、落盘取流、旧指标 CLI、模型对比、同步算法和历史证据文档已从提交面移除；本机 ignored 的 `runs/`、`data/` 和 `models/` 未被删除。

- 前端 JavaScript、启动脚本和 systemd 单元语法：通过。

以上是合成夹具和本机工程验收；不替代真实 C6c 连续长稳、云录像回放或目标域校准。

## 仍未关闭

- 真实目标设备连续长稳、段间隙、轻量门异常召回、模型实时系数和背压率。
- 事件时间与萤石云录像实际回放范围的一致性，以及不同浏览器的 HLS 播放兼容性。
- C6c 远场、噪声、电视 hard negative、多人、遮挡、夜视和真实跌倒正负样本的 held-out 校准。
- 至少 7 个合格日期的个人行为基线和已确认睡眠规律的长期覆盖。
- 项目 LICENSE、第三方 NOTICE、最终依赖锁、模型来源/许可证/摘要和全新环境安装验收。

因此当前对外口径只能是“本地工程演示作品”和“未验证试点”，不能声称临床有效、诈骗确认或公开发布就绪。
