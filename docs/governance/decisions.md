# 有效决策

状态：Active
更新时间：2026-09-01

本页只记录最终三域产品仍生效的决定。

| ID | 决定 | 影响 |
|---|---|---|
| DEC-001 | 产品以一位老人和一台目标 C6c 为中心 | 辅助摄像头不进入评分；所有长期变化只与本人过去 28 天比较 |
| DEC-002 | 跌倒、心理健康、诈骗独立输出 `0–3/null`，统一标记 `pilot_unvalidated` | `global_score=null`；不解释为概率、临床诊断或诈骗确认，不自动外部告警 |
| DEC-003 | 证据不足、数据过期或模型失败必须 fail closed | 不能用轻量扫描、缺失数据或模型失败补出 0 分 |
| DEC-004 | 正式产品连续处理、按 60 秒审计、按关键窗口送模 | 不再运行两小时落盘 cron；生产者与单模型消费者之间的背压显式审计 |
| DEC-005 | 连续原始录像由摄像头云服务管理，本机只归档实际风险候选窗口 | 默认事件前 10 秒至后 20 秒、30 天、每人 2 GiB；完整 60 秒段仍不落盘 |
| DEC-006 | 轻量运动与音频活动门只决定送模范围 | 只有姿态/ASR 成功处理的覆盖可支持“无候选”的 0 分 |
| DEC-007 | 心理健康行为侧至少 7 个日期、每天 3 个合格段后才建个人基线 | 不与人群比较，不做表情或声学情绪识别；已确认睡眠规律才可使用 |
| DEC-008 | 每自然月提醒填写 WHO-5，低于 13 分时心理域至少为 2 | 问卷不抵消更高行为风险，不填不补猜；public 不导出答案或分数，不解释为诊断 |
| DEC-009 | ASR 只保存风险命中的最长 120 字规范化片段 | 完整逐字稿不入库；owner 可见，public 完全移除 |
| DEC-010 | Web 只绑定 `127.0.0.1`，变更请求要求同源、CSRF 和 JSON | 不开放公网；本机媒体只通过 POST 后签发的短期随机令牌读取，不提供任意路径 |
| DEC-011 | 人工确认/驳回即时重算，但候选和复核审计不可覆盖删除 | 备注只在 owner 范围；服务重启后结果仍保留 |
| DEC-012 | owner/public 离线报告分离 | public 不含身份、设备、原始指标、转写、备注、路径、candidate 或精确事件时间 |
| DEC-013 | 异常回看优先使用 owner-only 本机 MP4，缺失时按事件窗口回退云端 | 本机路径不出 API；随机/云端 token 不持久化；删除个人数据会删除本机归档 |
| DEC-014 | 展示界面独立实现，只借鉴实时守护产品的信息组织 | 不复制无明确许可的第三方前端或同步算法代码 |
| DEC-015 | 提交仓库只保留最终产品运行、策略、测试和当前文档 | 历史实验代码与大资产不进入提交；需要保留的旧资产迁入 `/cache` 可恢复归档 |
| DEC-016 | 公开跌倒数据按受试者隔离开发/留出，策略冻结后留出只运行一次 | 标签不进入候选生成；登录节点只准备和校验数据，模型推理与批测必须走 Slurm 计算节点 |
| DEC-017 | 姿态权重外置并由边缘策略冻结名称、SHA-256、许可证与推理参数 | 文件缺失或摘要不符时姿态域 fail closed；权重与公开媒体不进入 Git 或 `/home` 提交面 |
| DEC-018 | 诈骗公开测试按消息摘要稳定分区，个人基线按家庭隔离；策略冻结后各留出只运行一次 | FBS/CASAS 原始数据只在 `/cache`；标签不进入规则；结果只能表述为词法与个人基线工程证据，不能表述为 ASR、心理结局或目标 C6c 准确率 |
| DEC-019 | 四份 JSON 运行策略作为 wheel 数据安装，demo 参考环境单独使用平台锁 | 非 editable 安装不依赖源码工作目录；模型权重和 edge 完整依赖继续外置并受发布门约束 |
| DEC-020 | 心理域“等级 2 连续三天”必须是三个相邻自然日 | 缺失或低覆盖日期不能桥接；正确性修订升为 policy `2026-08-31.2`，不重复使用已消耗的公开留出集 |
| DEC-021 | 提交用静态页由正式 owner 导出器生成并复刻部署 demo 的主要信息层级 | 只使用醒目标记的合成数据；问卷可在页面内筛查但不持久化、不改风险，复核和媒体入口只说明部署版行为；条款随单文件内嵌，public 导出继续脱敏 |

## 仍需 owner 决定

1. 项目 LICENSE、第三方 NOTICE 和 edge 完整依赖锁；demo 平台锁已经冻结。
2. 姿态与语音权重的许可证、摘要、携带或受控下载方式。
3. 真实目标设备 held-out 校准、长稳和轻量门表现达到何种门槛才可改变试点口径。
