# 设备能力矩阵

状态：Live Ledger v2.0
更新时间：2026-08-08

证据等级：E0=说明/假设，E1=fixture/公开集，E2=真实脱敏样本，E3=重复真机验证，E4=多周期验收。

## 设备边界

| 设备 | 数量 | 当前最高证据 | 角色 |
|---|---:|---|---|
| CS-C6c-V101-1J4WF | 1 | E2 | 单机位视频、姿态、动作和跌倒候选 |
| CS-EP-SDHY1 | 1 | E2 | 睡眠心率、呼吸率、状态和睡眠报告 |
| HK-Q1S4M-GL/LN | 1 | E2 | 辅助采集设备：仅开发期数据采集，不进入目标域结论（DEC-002 补充） |

第二机位、手环、门锁、RGB-D、压力步道和原始雷达不进入当前**生产**范围。HK-Q1S4M 是测试阶段辅助机位（另一房间），其数据可用于算法开发与调试，但因非目标机型，不能提升 C6c 目标域的证据等级或结论；held-out B 与正式 A/B 仍只用 C6c。

注意：8 kHz 窄带音频的 ASR/VAD 保真度低于 C6c 的 16 kHz AAC，语音指标开发仍以 C6c 音轨为准。

当前实物为 C6c 固件 V5.3.8 与 SDHY1。开放平台已验证设备枚举、能力查询、激活码和直播地址通路；token、签名地址、序列号与真实健康值只允许存在于受控本地环境。平台通用功能不自动等于目标 SKU 支持，能力等级只依据真实 API、媒体或重复真机证据提升。
