# 单机位目标设备采集规程

状态：Active v1.0
更新时间：2026-08-08

目标设备：1 × C6c（视频与 AAC 音频）、1 × SDHY1。

## 安全与同意

- 真实参与者必须有明确同意、用途、保留期限和删除责任人。
- 不采集未同意访客；多人场景使用已同意测试人员。
- 原始媒体和健康数据 owner-only，不进入 Git。
- camera 固定位置、云台、数字变焦和标定后才能采集正式指标样本。

## C6c 场景

| ID | 场景 | 目标 |
|---|---|---|
| C01 | 白天空房 | 人物误激活基线 |
| C02 | 白天自然行走 | 步速、步频、关键点可见率 |
| C03 | 远距自然行走 | 单机位尺度和覆盖退化 |
| C04 | 连续五次坐站（5xSTS） | 协议化五次坐站总用时和动作边界 |
| C05 | 白天弯腰/拾物 | 跌倒混淆负样本 |
| C06 | 白天床边躺卧/起身 | 横卧与正常睡眠动作混淆 |
| C07 | 家具局部遮挡 | 关键点和轨迹退化 |
| C08 | 夜间空房 | 夜视人物误激活基线 |
| C09 | 夜间行走/坐下 | 夜视步态与坐站退化 |
| C10 | 夜间床边躺卧/起身 | 夜视横卧混淆 |
| C11 | 白天安全模拟跌倒 | 正候选与人工 onset；仅在安全条件满足时 |
| C12 | 夜间安全模拟跌倒 | 夜视正候选与人工 onset；仅在安全条件满足时 |
| C13 | 行走中 180° 转身 | 协议化转身任务的开始、完成和用时 |
| C14 | 原地 360° 转身 | 协议化转身任务的开始、完成和用时 |
| C15 | 跪地/起身 | 跌倒混淆负样本 |
| C16 | 多人交叉 | track 连续性和错误关联 |

C01～C12 保留既有场景编号；C04 的正式指标任务收敛为 5xSTS。C13～C16 是 2026-08-08 新增场景。开发集 A 与 held-out 集 B 均覆盖 C01～C10、C13～C16；C11/C12 只有在同意、保护人员、软垫和停止条件齐全时采集。除 C04 外，动作类 clip 至少包含三次完整重复；C04 每段完成一组连续五次坐站，推荐两个独立 clip，不强制单段连续做三组。

每段记录机位高度、俯仰角、标定摘要、距离、光照、遮挡、场景、动作、参与者引用、媒体摘要和实际帧时间。

## C6c 语音场景

语音只用于辅助跌倒事件复核，不直接生成风险分或临床结论。开发集 A 与 held-out 集 B 均使用以下编号；B 必须在模型、文本规范化、词表、阈值和 candidate policy 冻结后运行。

| ID | 场景 | 目标 |
|---|---|---|
| V01 | 静音与房间噪声 | VAD 和 Voice FP/hour 基线 |
| V02 | 无目标语义的普通对话 | 普通话 CER 与 candidate FP |
| V03 | 直接求助表达 | `help_request` recall 和检测延迟 |
| V04 | 跌倒相关表达 | `fall_related` recall 和检测延迟 |
| V05 | 否定、转述和引用 | 语义 hard negative |
| V06 | 电视/手机播放 | 回放 hard negative |
| V07 | 1 m、3 m、5 m 与低音量 | 距离和音量退化 |
| V08 | 双人交替和重叠发言 | 多人/overlap 退化 |
| V09 | 同步说词并举手或拍手 | 音视频 PTS 对齐误差 |

语音正式 clip 使用同一容器内音轨，记录 codec、采样率、声道、audio time base、PTS 连续性、距离、音量层级、背景声和播放源状态。至少使用两名已同意成年参与者；不得为了扩大数据规模采集与当前指标无关的私人对话。

V01～V09 只标注 speech/non-speech 区间、owner-only 普通话逐字稿、`help_request` / `fall_related` / `negative`、目标 onset、否定/转述和 V09 音视频 onset。诈骗、声纹、情绪、认知、抑郁或临床标签不得写入当前数据集定义。

## SDHY1 样本

至少取得一晚脱敏响应并记录：接口族、设备/服务版本、时区、观察时间、报告时间、心率/呼吸单位、在离床状态、就寝/入睡/醒来/起床边界、睡眠时长单位以及 null/缺失/离线表达。

## 标注

- 行走：有效区间、有效步数、脚部可见性和人工计时参考。
- 5xSTS：任务开始、每次臀部离座/接触、稳定站立/坐稳及第五次结束时刻。
- 转身：C13/C14 任务类型、方向、开始、完成和中断状态；任务角度由协议和人工参考确认。
- 跌倒：双人独立标注、裁决 onset/interval 和排除原因。
- 语音：VAD 区间、规范化逐字稿、candidate 类别/onset、否定/转述和音视频同步参考。
- 标注不得进入推理输入；held-out 输出生成前冻结策略。

## 验收

- 所有文件有摘要、受控相对路径和来源绑定。
- 核心场景结构完整，无重复媒体。
- 单机位不可见、严重遮挡、标定漂移和动作不完整能够显式不可评估。
- 语音可计算 VAD precision/recall/F1、普通话 CER、candidate precision/recall/F1、Voice FP/hour、检测延迟和 V09 PTS 对齐误差。
- 音轨缺失、音频 PTS 中断或语音模型失败时语音显式 `not_assessable`，视频与睡眠链不被阻塞。
- 原始音频与逐字稿 owner-only；public evidence 只保留计数、质量、状态和限制。
- SDHY1 mapping 的单位、时间、值域和缺失语义齐全。
- 真实样本只能提升对应能力，不自动提升模型准确率、风险策略或长稳等级。
