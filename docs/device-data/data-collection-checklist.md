# KangShield 数据采集详细清单

状态：Active v1.0
更新时间：2026-08-08
适用设备：`1 × CS-C6c-V101-1J4WF`、`1 × CS-EP-SDHY1`

本清单用于开发集 A、held-out 集 B、视频/语音长稳数据和 SDHY1 三晚数据采集。原始媒体、逐字稿与健康数据均为 owner-only，不进入 Git。本项目输出工程风险指标与辅助 candidate，不提供临床诊断。

## 1. 预计采集规模

| 数据 | 最低数量 | 推荐数量 | 说明 |
|---|---:|---:|---|
| 开发集 A | 14 段 | 28 段 | C01～C10、C13～C16；推荐每场景 2 段 |
| Held-out 集 B | 14 段 | 28 段 | 参数冻结后采集；不得与 A 使用同一媒体 |
| C11/C12 模拟跌倒 | 0 段 | 每场景 2～3 段 | 仅在全部安全条件满足时采集 |
| 取流长稳 | 31 × 60 秒 | 31 × 60 秒以上 | 同时满足 wall/media 时长门 |
| 白天空房负样本 | 30 分钟 | 60 分钟以上 | 用于人物误激活与 FP/hour |
| 夜间空房负样本 | 30 分钟 | 60 分钟以上 | 开启真实夜视模式 |
| 自然活动负样本 | 30 分钟 | 1～2 小时 | 行走、坐卧、拾物、跪地、床边和多人活动 |
| 语音开发集 A | V01～V09 各 1 组 | 各 2 组 | 至少 2 名已同意成年参与者；用于冻结 VAD/ASR/candidate 参数 |
| 语音 held-out 集 B | V01～V09 各 1 组 | 各 2 组 | 与 A 不同录音；冻结后运行 |
| 语音负样本暴露 | 20 分钟 | 60 分钟以上 | 普通对话、电视/手机播放和环境噪声，用于 Voice FP/hour |
| SDHY1 完整夜 | 1 晚 | 连续 3 晚 | 必须能审计时区、覆盖和缺失语义 |

除标准化 5xSTS 外，动作类 clip 每段至少包含 3 次完整重复，建议长度 60～90 秒。C04 每段至少完成 1 组连续五次坐站，推荐采集 2 个独立 clip；不应为了满足通用重复数强制连续完成 3 组。推荐使用 2 名知情同意的成年参与者；C16 至少需要 2 人。

## 5. 语音数据清单

语音数据只服务于已冻结的辅助链：语音活动检测、普通话转写、`help_request` / `fall_related` candidate、Voice FP/hour 和音视频 PTS 对齐。不得从这批数据扩展诈骗、声纹、情绪、认知、抑郁或临床评分任务。

| ID | 场景 | 最低内容 | 指标/质量用途 | A | B |
|---|---|---|---|---|---|
| V01 | 静音与房间噪声 | 无人声，覆盖设备底噪和常见环境声 | VAD FP、Voice FP/hour | [ ] | [ ] |
| V02 | 普通对话 | 不含求助或跌倒语义的自然普通话 | ASR CER、candidate FP | [ ] | [ ] |
| V03 | 直接求助 | “救命”“帮帮我”等不同自然表达，不表演真实危险 | `help_request` recall/latency | [ ] | [ ] |
| V04 | 跌倒相关描述 | “我摔倒了”“起不来了”等不同自然表达 | `fall_related` recall/latency | [ ] | [ ] |
| V05 | 否定与转述 | “我没有摔倒”、讨论或引用目标词 | hard-negative precision | [ ] | [ ] |
| V06 | 电视/手机播放 | 播放含目标词和不含目标词的内容 | 回放 hard-negative、Voice FP/hour | [ ] | [ ] |
| V07 | 远距与低音量 | 1 m、3 m、5 m；普通音量和低音量 | 距离分层 VAD/ASR/candidate 退化 | [ ] | [ ] |
| V08 | 多人交替与重叠 | 两人交替发言并包含短时重叠 | overlap 质量与误触发 | [ ] | [ ] |
| V09 | 音视频同步提示 | 说出提示词的同时举手或拍手，至少 5 次 | audio/video PTS 对齐误差 | [ ] | [ ] |

### 5.1 逐项标注与指标映射

| 输出指标 | 必需人工参考 | 最低统计 |
|---|---|---|
| VAD precision / recall / F1 | 每段 speech / non-speech 起止区间 | 按时间区间或固定帧粒度计算 TP/FP/FN |
| 普通话 ASR CER | owner-only 规范化逐字稿；保留原始录音对应关系 | 总字数、替换、删除、插入和 CER |
| candidate precision / recall / F1 | `help_request`、`fall_related`、`negative` 标签及 onset | 每类 TP/FP/FN、宏平均 F1 和检测延迟 |
| Voice FP/hour | 已确认无目标语义的有效音频暴露 | FP 数、有效小时数和场景分层 |
| 音视频对齐误差 | V09 可见动作 onset 与可听提示 onset | 每次绝对误差、P50、P95、最大值 |
| 运行性能 | 音频时长、阶段开始/结束时间和资源峰值 | RTF、P95 segment latency、CPU/GPU 内存 |

### 5.2 每个语音 episode 必记

- [ ] `dataset_revision`、V01～V09 `scenario_id`、`take_id` 和脱敏参与者引用。
- [ ] 录制距离、音量层级、说话人数、背景声类型和播放源状态。
- [ ] audio codec、采样率、声道、time base、起止 PTS 和连续性检查结果。
- [ ] VAD 区间、owner-only 逐字稿、candidate 类别、目标 onset 和否定/转述标记。
- [ ] V09 同时标注视频动作 onset 与音频提示 onset。
- [ ] 文件 SHA-256、字节数、同意记录引用和访问权限。
- [ ] public evidence 仅含计数、质量、状态和限制，不含录音或逐字稿。

### 5.3 语音 A/B 冻结门

- [ ] A 集已覆盖 V01～V09，并据此冻结 VAD、ASR、文本规范化和 candidate policy revision。
- [ ] B 集与 A 集无重复文件、无同源切片，参与者/距离/背景条件尽量形成独立变化。
- [ ] B 标签在推理前冻结，且标注和逐字稿不进入模型输入。
- [ ] B 后如调整词表、否定窗口、阈值或模型，建立新 policy revision 和独立 B2。
- [ ] 音轨缺失、PTS 中断或模型失败时，语音输出 `not_assessable`；视频和睡眠链继续运行。

- [ ] B 集已封存，模型运行前不再修改。
- [ ] 推理只运行冻结的三模型配置。
- [ ] B 集运行后只分析，不原地调参。
- [ ] 如需调参，建立新 policy revision 和独立 B2。

## 11. 最终验收清单

### 数据完整性

- [ ] A 覆盖 C01～C10、C13～C16。
- [ ] B 覆盖 C01～C10、C13～C16。
- [ ] 动作类 clip 均有至少 3 次完整重复。
- [ ] C11/C12 已采集，或明确记录安全原因未采集。
- [ ] 语音 A 与 B 均覆盖 V01～V09，且文件和同源切片不重复。
- [ ] 语音负样本有效暴露不少于 20 分钟，并可计算 Voice FP/hour。
- [ ] 三晚 SDHY1 数据均有完整性结果。
- [ ] 长稳和 FP/hour 暴露时长可分别计算。

### 质量与来源

- [ ] 所有文件摘要与字节数匹配。
- [ ] 没有重复媒体。
- [ ] 时间戳连续性已检查。
- [ ] 关键点和脚部可见性可以计算。
- [ ] track 中断可以识别。
- [ ] 可计算 VAD F1、普通话 CER、两类 candidate precision/recall/F1 和检测延迟。
- [ ] V09 可计算音视频 PTS 对齐误差；音频断轨或时间戳中断会得到 `not_assessable`。
- [ ] 标定缺失或漂移会得到 `not_assessable`。
- [ ] 动作不完整会得到 `not_assessable`。
- [ ] 睡眠语义不足会得到 `blocked_semantics`。

### 隐私与报告

- [ ] 原始音视频、逐字稿和健康值仅在 owner-only 路径中。
- [ ] Git 中不存在媒体、健康值、凭据和设备序列号。
- [ ] owner report 可以包含真实分项值。
- [ ] public evidence 不包含 observation、原始值或人员标识。
- [ ] `global_score=null`。
- [ ] 未冻结评分项返回 `policy_not_frozen`。
- [ ] 跌倒 candidate 与人工裁决独立展示，不并入风险总分。
- [ ] 语音 candidate 只显示类别、时间、质量和裁决状态，不在 public evidence 中显示逐字稿。
